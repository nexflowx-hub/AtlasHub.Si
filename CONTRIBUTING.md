# Contributing

This is a proprietary AtlasHub repository.

## Workflow

1. Work in the `nexflowx-hub` fork.
2. Create a focused feature branch.
3. Keep changes reviewable.
4. Open a pull request against the fork's `main`.
5. After validation, promote the approved change to the upstream AtlasHub repository.

Direct experimental commits to the upstream repository are not part of the standard workflow.

## Commit style

Prefer conventional prefixes:

- `feat:`
- `fix:`
- `docs:`
- `chore:`
- `refactor:`
- `test:`
