## Purpose

`AtlasHub.SI` is the primary public-facing AtlasHub property and the canonical entry point for the ecosystem.

Planned public architecture:

- **atlashub.si** — institutional gateway, solutions, insights and ecosystem navigation
- **app.atlashub.si** — authenticated intelligent workspace
- **academy.atlashub.si** — learning, courses, workshops and learning paths
- **editions.atlashub.si** — books, eBooks, executive papers, reports and editorial research

`atlashub.digital` remains a defensive/fallback brand asset. `atlas-si.com` is reserved for infrastructure and specialized technical services where appropriate.

## Repository role

This repository owns the public AtlasHub.SI website shell, ecosystem navigation and institutional presentation.

## Development workflow

Development follows a two-stage model:

1. **NexFlowX-Hub fork** — active development, experimentation and validation.
2. **AtlasHub upstream** — reviewed and approved releases are promoted to `atlashub-digital/AtlasHub.Si`.

Do not push experimental work directly to the upstream repository.

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Baseline stack

- Next.js
- React
- TypeScript
- CSS design tokens
- Vercel-compatible deployment

## Brand

AtlasHub design principles:

- premium and restrained;
- dark navy / near-black foundations;
- electric blue used as signal, not decoration;
- human + systems + intelligence;
- no gratuitous sci-fi or generic AI imagery.
